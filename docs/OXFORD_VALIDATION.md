# Oxford 工作台验证 · 2026-11-12

环境：Windows、官方 DeepSeek Harness Desktop 0.2.0-rc.2。测试用的 Web/Desktop 配置与日常会话分开。

| 检查 | 结果 |
|---|---|
| 官方签名的 Windows 桌面版 | 在独立桌面配置中实际打开应用，读到「应用 / 编辑 / 测量」三个菜单；用鼠标点第三项进入 Oxford，再点返回 DSH。没有修改 Electron 安装文件。 |
| 浏览器中真实 DSH 界面 | 检查两层循环产生 6 次采样；二维设定示例产生 14 个动作；无效源码报告正确行号并清除旧预览。 |
| 四种主题 | 在实际 DSH 内切换、捕获测量页面；检查未绑定时无读数、窄屏布局、两个会话分栏进入测量后返回原两栏。截图使用无个人会话的测试环境。 |
| 安装和主机接口 | 四个插件可共存，原有用户配置保留。测试覆盖真实 CPython 编译、DSH 会话认证与本机控制边界，以及内存模拟的原生管道应答和卸载。 |
| Oxford 1.3.1 原生端 | Windows x86 / .NET Framework 4.7.2 构建成功；四色适配已接入原生绘制。实验机 Windows 应用程序控制阻止本次未获信任的 Oxford.exe 启动，故原生窗口换肤、真实连接、采集与停止未做实机验收。 |

代码中的原生协议测试使用测试替身，不代表硬件验收。上述 UI 测试未发送模型任务或仪器命令。安装完成后在新电脑可先检查「测量 → 编译预览」，本地可信原生构建的绑定与联机调试见 [原生说明](../native/README.md)。
